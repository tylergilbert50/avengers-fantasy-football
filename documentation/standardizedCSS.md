# Standard CSS Property Order

Here’s the conventional order CSS properties should follow:

---

## 1. Positioning

- `position`
- `top`, `right`, `bottom`, `left`
- `z-index`

---

## 2. Box Model

- `display`
- `flex-direction`, `flex-wrap`, `justify-content`, `align-items`, etc.
- `width`, `height`
- `margin`
- `padding`

---

## 3. Typography

- `font-family`
- `font-size`
- `font-weight`
- `font-style`
- `line-height`
- `text-align`
- `text-decoration`
- `color`

---

## 4. Visual

- `background`
- `border`
