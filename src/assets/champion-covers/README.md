# Championship comic covers

One cover per title, named after the season it was won:

    2021.webp
    2022.webp
    2023.webp
    2024.webp
    2025.webp   <- the cover the book itself opens with

Drop a file in and the Champions page picks it up on the next build — no code
change. `.webp`, `.png` and `.jpg` all work. A season with no cover here shows a
blank issue ("cover to come") in its place, so the shelf never has a gap in the
run.

Portrait proportions, please — they are shown at 2:3 and cropped from the top,
so a cover with its title lettering up top survives the crop.
