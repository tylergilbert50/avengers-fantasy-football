# Number-one-pick artwork

Drop a cutout here named after the player, and the Draft History page picks it
up on the next build — no code change. The name is slugified, so:

    Ja'Marr Chase        -> jamarr-chase.webp
    Christian McCaffrey  -> christian-mccaffrey.webp
    Jonathan Taylor      -> jonathan-taylor.webp
    Justin Jefferson     -> justin-jefferson.webp

`.webp`, `.png` and `.jpg` all work. A season whose top pick has no file here
simply renders without art; nothing breaks.
